# PXT Smart Infrastructure — User & Operator Manual

## Navigation Views

1. **Overview Dashboard**: Displays overall SCADA operational status, 6 KPI cards, domain sector health, real-time telemetry stream, system events, and active incidents.
2. **Devices Inventory**: Search devices by ID or name, filter by sector or status, sort by attribute, toggle grid/table view, and execute quick control actions (Power, Restart, Fail, Recover, Anomaly).
3. **Device Detail Inspector**: Inspect individual node telemetry gauges, view historical Recharts timeseries, execute command ACK actions, and calibrate sensor parameters.
4. **Topology Visualizer**: Dynamic visual representation of virtual infrastructure node interconnections with canvas zoom/pan controls (`ZoomIn`, `ZoomOut`, `ResetZoom`) and click-to-inspect node details modal.
5. **Incident Management Console**: Differentiates Active Unresolved Incidents, Acknowledged Alerts, and Resolved Historical Incidents with one-click ACK & Resolve actions.
6. **Automation Rule Builder**: Configure dynamic backend threshold rules (`>`, `<`, `==`, etc.), toggle rule enable state, and view trigger execution history.
7. **Audit Trail**: Searchable log of administrative actions, user logins, device commands, and mode changes.
8. **System Health & Operating Mode Switcher**: View process state diagnostics and toggle between **Mode A: SIMULATION MODE** (25 Virtual Simulators) and **Mode B: PHYSICAL HARDWARE MODE** (Actual Hardware Node Ingestion).
